5
Alimentação via Powerbank
›
Powerbank (USB-A) → Cabo USB-A/Micro-USB → ESP32 DevKit V1

O ESP32 recebe 5V pelo USB, regula internamente para 3.3V e distribui para microSD e acelerador. O MAX98357A usa o pino VIN (5V direto do regulador onboard).

💡
Fixação na bike: Use velcro dupla-face para prender o powerbank ao quadro. Posicione a caixa eletrônica perto do powerbank para minimizar o cabo USB. Abraçadeiras de nylon como segurança extra.
🔊 Preparação dos Áudios

Os sons do motor são o coração do projeto. A qualidade aqui define se o resultado será impressionante ou mediano.

1
Estrutura do cartão SD
›

Formate o cartão SD em FAT32 e crie a seguinte estrutura:

/audio/
 ├── 0001.wav  → idle (marcha lenta, loop contínuo)
 ├── 0002.wav  → low (aceleração leve)
 ├── 0003.wav  → medium (aceleração média)
 ├── 0004.wav  → high (aceleração máxima)
 ├── 0005.wav  → buzina
 ├── 0006.wav  → partida
 └── 0007.wav  → desaceleração
ℹ️
Formato obrigatório: WAV, 16-bit PCM, Mono, 22050 Hz. Outros formatos (MP3, stereo) exigem código mais complexo e aumentam latência.
2
Onde baixar os sons
›

🆓 Fonte gratuita: freesound.org

Acesse freesound.org e pesquise por:

  • "motorcycle engine loop" license:CC0
  • "motorbike idle loop"
  • "engine revving loop"
💡
Procure sons com licença CC0 (domínio público). Baixe as versões originais e converta para WAV 22050Hz mono usando Audacity (gratuito).
3
Converter sons com Audacity
›
  1. Abra o arquivo de áudio no Audacity
  2. Menu Tracks → Stereo to Mono (se necessário)
  3. Menu Tracks → Resample → selecione 22050 Hz
  4. Ajuste o ponto de loop: o som deve ser contínuo sem clique
  5. Menu File → Export → Export as WAV
  6. Selecione: Signed 16-bit PCM
  7. Renomeie para 0001.wav, 0002.wav, etc.
⚠️
Loop sem clique: O ponto de corte do arquivo deve ser em zero-crossing (onde a onda cruza o zero). O Audacity tem a opção "Find Zero Crossings" no menu Edit para ajudar nisso.
💻 Firmware — Código Completo

Cole no Arduino IDE. Instale as bibliotecas necessárias antes de compilar.

1
Instalar bibliotecas necessárias
›

No Arduino IDE, vá em Sketch → Include Library → Manage Libraries e instale:

  • ESP32 — Adicione a placa pelo Boards Manager: URL https://dl.espressif.com/dl/package_esp32_index.json
  • ESP32-audioI2S de schreibfaul (busque por "ESP32 Audio I2S")
  • SD — já incluída no ESP32 core
ℹ️
Em Tools → Board, selecione "ESP32 Dev Module". Em Tools → Partition Scheme, selecione "Default 4MB with spiffs".
2
Código principal — main.ino
›
// ================================================
// Bicicleta Infantil com Som de Moto — ESP32
// Conexões: ver guia de montagem
// ================================================

#include "Audio.h"
#include "SD.h"
#include "SPI.h"

// ---- Pinos ----
#define SD_CS     5
#define SD_MOSI   23
#define SD_MISO   19
#define SD_SCK    18

#define I2S_DOUT  25
#define I2S_BCLK  27
#define I2S_LRC   26

#define THROTTLE_PIN 34
#define HORN_PIN     32

// ---- Configuração ----
#define THROTTLE_MIN   800
#define THROTTLE_MAX   3800
#define VOLUME_MIN     5
#define VOLUME_MAX     21

Audio audio;

int currentLayer = 0;   // 0=idle 1=low 2=med 3=high
bool hornPlaying = false;
unsigned long lastChange = 0;
const char* layers[] = {
  "/audio/0001.wav",  // idle
  "/audio/0002.wav",  // low
  "/audio/0003.wav",  // medium
  "/audio/0004.wav"   // high
};

void setup() {
  Serial.begin(115200);
  
  // Inicializa SPI para SD
  SPI.begin(SD_SCK, SD_MISO, SD_MOSI, SD_CS);
  if (!SD.begin(SD_CS)) {
    Serial.println("ERRO: Cartão SD não encontrado!");
    while(1);
  }
  
  // Configura I2S → MAX98357A
  audio.setPinout(I2S_BCLK, I2S_LRC, I2S_DOUT);
  audio.setVolume(VOLUME_MIN);
  
  // Pinos de entrada
  pinMode(THROTTLE_PIN, INPUT);
  pinMode(HORN_PIN, INPUT_PULLUP);
  
  // Inicia com som de partida
  audio.connecttoFS(SD, "/audio/0006.wav");
  delay(2000);
  
  // Começa em idle
  audio.connecttoFS(SD, layers[0]);
  currentLayer = 0;
}

void loop() {
  audio.loop();  // SEMPRE chamar no loop principal
  
  // --- Lê acelerador ---
  int raw = analogRead(THROTTLE_PIN);
  raw = constrain(raw, THROTTLE_MIN, THROTTLE_MAX);
  int throttle = map(raw, THROTTLE_MIN, THROTTLE_MAX, 0, 100);
  
  // --- Define camada de áudio ---
  int targetLayer;
  if (throttle < 10)        targetLayer = 0;  // idle
  else if (throttle < 35)   targetLayer = 1;  // low
  else if (throttle < 70)   targetLayer = 2;  // medium
  else                       targetLayer = 3;  // high
  
  // --- Volume proporcional ao acelerador ---
  int vol = map(throttle, 0, 100, VOLUME_MIN, VOLUME_MAX);
  audio.setVolume(vol);
  
  // --- Buzina (prioridade máxima) ---
  if (digitalRead(HORN_PIN) == LOW && !hornPlaying) {
    audio.stopSong();
    audio.connecttoFS(SD, "/audio/0005.wav");
    hornPlaying = true;
    currentLayer = -1;  // força retomada
  }
  
  // --- Troca de camada (com debounce 200ms) ---
  if (!hornPlaying 
      && targetLayer != currentLayer
      && millis() - lastChange > 200) {
    audio.stopSong();
    audio.connecttoFS(SD, layers[targetLayer]);
    currentLayer = targetLayer;
    lastChange = millis();
  }
}

// --- Callback: ao terminar um arquivo, volta ao idle ---
void audio_eof_mp3(const char *info) {
  if (hornPlaying) {
    hornPlaying = false;
  }
  // Loops automáticos → relança o arquivo atual
  audio.connecttoFS(SD, layers[currentLayer >= 0 ? currentLayer : 0]);
}
3
Upload e Teste
›
  1. Conecte o ESP32 ao computador via USB
  2. Em Tools → Board selecione ESP32 Dev Module
  3. Em Tools → Port selecione a porta COM do ESP32
  4. Clique em Upload (seta →)
  5. Abra o Serial Monitor (115200 baud) para ver mensagens de debug
  6. Teste o acelerador e o botão de buzina antes de montar na bike
⚠️
Se aparecer erro "SD não encontrado": verifique os fios SPI, confirme que o cartão está formatado em FAT32, e que os arquivos WAV estão na pasta /audio/.
💡
Use o Serial Monitor para imprimir os valores do ADC do acelerador: Serial.println(raw); dentro do loop. Ajuste THROTTLE_MIN e THROTTLE_MAX conforme os valores reais do seu acelerador.
